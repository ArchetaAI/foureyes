# foureyes

Give it a spec and acceptance tests the agent never sees; get back code that passes them, plus a report of what's still risky.

**First target:** TypeScript repos, for both repairing existing code and building from a spec.

**Not** a new coding agent, a multi-agent swarm or a prompt pack. It's built to run on top of Claude Code, Codex and OpenCode.

**Pre-alpha. Nothing works yet.** Built in public: every architectural decision is recorded in [`docs/decisions/`](docs/decisions/) before any code is written.
