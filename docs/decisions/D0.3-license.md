# D0.3: License
Status: Decided | Date: 2026-10-13

## Context
The repository has been public since it was created, so until a license is added, all rights are reserved and nobody may legally use or contribute to it. The license has to suit the goal of adoption: companies running foureyes in their own pipelines, and outside contributors adding benchmark tasks, gates, triage policies and adapters.

## Options considered
| Option | What it is | Why not chosen |
|---|---|---|
| **Apache-2.0** | Permissive, with an explicit patent grant and terms for contributions | **Chosen** |
| MIT | The shortest permissive license | No patent grant and no stated terms for contributions; companies wiring it into CI get less legal certainty |
| MPL-2.0 | Copyleft per file | Uncommon for agent and developer tooling; adds hesitation without protecting anything we need protected |
| AGPL-3.0 | Strong copyleft that extends to hosted services | Many companies ban it outright, which costs adoption and contributors.

## Decision
foureyes is licensed under **Apache License 2.0**.

- `LICENSE` holds the Apache-2.0 text verbatim, unedited, including the appendix. It was checked against the SPDX reference text on 2026-10-13 and matches apart from whitespace.
- `NOTICE` holds the attribution: "Copyright 2026 Versen, trading as Archeta AI". Versen is the registered business; Archeta AI is the name it trades under.
- Source files don't carry per-file license headers. The package manifest declares `Apache-2.0` as its license once the harness language is chosen (D0.5).
- Contributions come in under the same license, per Apache-2.0 Section 5. Whether contributors sign off their commits (DCO) or sign a contributor agreement (CLA) is decided with the contribution lanes (D5.1).

## Consequences: what this commits us to and what it rules out
- Anyone can use, modify, sell or host foureyes, including in closed products, provided they keep the license and NOTICE. We accept that someone else could offer a hosted version.
- Any paid product from Archeta AI is built as separate code on top of foureyes, not by restricting the core.
- Once outside contributions are merged, relicensing the core needs every contributor's consent. Changing the core to a non-open license is not a plan we keep open.
- Dependencies must have licenses compatible with Apache-2.0. GPL-2.0-only code cannot be included.
- Benchmark task content in the repo is covered by this license too. The license does not stop task content from ending up in model training data; where hidden tests, held-out tasks and reference solutions live is decided separately (D1.4).

## Revisit if
- A dependency we need has a license that's incompatible with Apache-2.0.
- Companies we want as users report legal friction with Apache-2.0 (not expected).
